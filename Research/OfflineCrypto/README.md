# Offline encrypted-response research

A separate Swift package for Linux/macOS research; not linked into Trio, the iOS
app, or the primary Swift package. Requires libsodium development files
(`apt install libsodium-dev` or `brew install libsodium`). Run:

```sh
swift test --package-path Research/OfflineCrypto
```

The decrypt-only Swift API delegates XChaCha20-Poly1305 to libsodium. It accepts
one assembled offline envelope, ciphertext + tag + appended 24-byte nonce,
then parses the authenticated LE UInt32 reboot / UInt64 read-counter tail.
Input is bounded to the existing 15 × 19-byte framing model; it is not a generic
arbitrary-length AEAD interface. No encryption or outbound command API is exposed.

The actor rejects repeated/lower counters and any change in reboot epoch. Its
baseline must be supplied explicitly; it does not infer a safe new epoch. It
advances its in-memory floor after authenticating a message, even if subsequent
CRC or status-schema validation fails, and never advances on authentication
failure. It uses the existing explicit Baz00k V05.00.52 / protocol 1.3 parser.

IMPORTANT: this is not a production session manager. There is no durable journal,
trusted baseline acquisition, key storage/zeroization guarantee, key renewal,
identity authentication, write-counter reservation, retries, network or BLE.
Recreating it with an older baseline permits replay; callers must not interpret
its in-memory floor as crash-safe storage. Swift arrays may retain copied keys.
Do not use real session keys in this experiment.

Eight XCTest cases passed locally on Ubuntu with Swift 6.4.1 and libsodium
1.0.18 (25 October 2026). Fixtures are synthetic status responses generated by
an independent Python caller into libsodium, not independent cipher implementations
or pump captures. Fixed JSON fixtures are committed; normal tests do not generate
or encrypt messages. The optional fixture generator only encodes synthetic status
bodies, not therapy commands. Mutations cover every ciphertext/tag/nonce byte,
truncation, wrong keys, nonce placement, counter order, CRC failure and reboot changes.
The primitive's security is inherited from libsodium, not established by these tests.
